# StockPrice Prediction 

This project predicts Tesla (TSLA) and Google (GOOGL) stock prices using machine learning and deep learning models. It applies LSTM neural networks with robust evaluation techniques to achieve accurate time series forecasting.

🚀 Features

Works with Tesla & Google historical stock data.

Preprocessing and feature scaling for sequential data.

LSTM-based deep learning model for time series forecasting.

Performance evaluation with metrics like MAE, RMSE, and R² score.

Visualization of actual vs. predicted stock prices.

🧪 Results

The LSTM model effectively captures trends in Tesla & Google stock prices.

Predictions align closely with real market data.
